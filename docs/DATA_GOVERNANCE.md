# Data governance

## Evidence labels

Every traveller-visible claim is labelled as one of:

- **Verified journey** — evidence indicates the contributor physically completed the stated segments.
- **Community report** — a time-limited observation that has passed moderation but is not independently verified.
- **Official information** — a dated statement from an attributable authority or operator.
- **General guidance** — non-destination-specific advice, clearly separated from current conditions.

## Expiry defaults

| Report type | Default active lifetime |
| --- | ---: |
| Parking full / crowding | 4 hours |
| Muddy or slippery trail | 48 hours |
| Road damaged | 14 days |
| Public transport disrupted | 24 hours |
| Closed / restricted | Until official recheck, maximum 7 days without reconfirmation |
| Vehicle suitability confirmation | Confidence decay begins after 30 days |

Moderators can shorten expiry but extensions require a new observation or official source.

## Seed-data warning

The representative destination records in this repository demonstrate product behaviour. They are not a publishable field dataset and must be independently verified before travellers rely on them.
